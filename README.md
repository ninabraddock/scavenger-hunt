# Scavenger /hunt

### Contributors: 
Nina Braddock & Rachel Rose

### Summary of proposed project:
Our group is planning on creating a Scavenger hunt. The start screen will be a top down view of the board. The player will then be able to walk along the path to the various destinations on the map. Each destination will bring the player to a separate screen where they will need to find a specific item. The first location is a mountian, where you need to find snow! The seconf location is a city where you need to fidn a blue window. Finally the last location is a beach where you will need to find teh purple bubble. After the item is found, the user will be able to proceed to the next destination along the path. If the user has successfully gone through all destinations then the end screen will appear! Then they have won! 

### Which size project are you proposing? 
Large (200 pts)

### The operating system(s) you have run the project on
The project runs on Apple and Windows OS. No needed added installations besides standard openGL in class stuff
